## 🛠️ Getting Started (Local Development)

### Prerequisites
* **Node.js:** `v20.0.0` or higher
* **npm:** `v10.0.0` or higher

### 1. Installation
Clone the repository and install all verified dependencies:
```bash
git clone https://github.com/mihora-tech/mihora.git
cd mihora
npm install
```

### 2. Run Development Server
Launches the Vite dev server with Hot Module Replacement on `http://localhost:3000`:
```bash
npm run dev
```

### 3. Production Build & Static Route Pre-rendering
Compiles the React application and automatically triggers `scripts/generate-routes.js` to produce static HTML snapshots for deep routes (`/company`, `/services`, `/engineering`, `/docs`, etc.):
```bash
npm run build
```

The resulting distribution folder (`dist/`) is self-contained and immediately ready to be deployed to **GitHub Pages**, **Cloud Run**, **Vercel**, or an **Nginx/Apache** cluster.

### 4. Type Checking & Verification
Verifies syntax, imports, and strict TypeScript types across the entire repository:
```bash
npm run lint
```

## 🔍 Search Engine Optimization & Indexing

MIHORA.TECH incorporates an enterprise-grade SEO architecture built specifically for modern search crawlers and AI reasoning engines (Perplexity, ChatGPT, Gemini):

2. **Microsoft Bing IndexNow:** Instant crawling trigger configured and tested. To manually re-submit all site URLs directly to Bing's index:

3. **Strict Meta Description Validation:** Every page description adheres to search engine standards (between 25 and 160 characters) to ensure zero indexing penalties.
4. **Pre-rendered Noscript Payloads:** Search engine bots that do not execute client-side JavaScript receive complete server-rendered summaries, headings, and founding attributions instantly.
